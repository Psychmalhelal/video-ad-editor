# ملف الهوية البصرية — محمد الهلال

المستخدم عنده **حسابان**. اسأله بأول سطر: **«الفيديو لأي حساب — psych_malhelal ولا alhelal_triangle؟»**
ثم انسخ `theme.json` المناسب من تحت إلى `<work>/theme.json`، وانسخ الشعار `logo.png`.
الستايل المطلوب = نفس ستايل السكل الافتراضي (أيقونات خطية بيضاء، مشاهد مرسومة بالكود) — الرابط اللي أعطاه هو مستودع السكل نفسه.

⛔ صفر تعديل لوني على الفيديو (grade:false) — قرار ثابت.
الأرقام غربية دائماً. الكابشن عربي متزامن بالكلمة.

## الحساب الأول — @psych_malhelal
محتوى: معلومات علم النفس، مقابلات، توعية.

```json
{
  "bg": "#38623b",
  "ink": "#FFFFFF",
  "acc": "#ffde59",
  "clay": "#d9bd4a",
  "mut": "#a9ccab",
  "font": "Tajawal",
  "handle": "@psych_malhelal",
  "logo": "logo.png",
  "grade": false,
  "badge": false,
  "faceAnchor": 0.30,
  "badgeUntil": 0
}
```
- خلفية: أخضر غامق `#38623b`
- تمييز: أصفر `#ffde59`
- ثانوي/خافت: أخضر فاتح `#a9ccab`
- نص فوق الخلفية: أبيض
- الخط: **Tajawal** (اختاره كلود — نظيف ودافئ وعالي الوضوح للمحتوى المعلوماتي؛ الهوك بوزن 800/900، النص 500)

## الحساب الثاني — @alhelal_triangle
محتوى: برنامج «مثلث الصحة النفسية» التدريبي (٣ محاور: روحي/جسدي/معرفي) — معلومات وإعلانات.

```json
{
  "bg": "#6d8b81",
  "ink": "#FFFFFF",
  "acc": "#ffde59",
  "clay": "#d9bd4a",
  "mut": "#EDE6D6",
  "font": "Cairo",
  "handle": "@alhelal_triangle",
  "logo": "logo.png",
  "grade": false,
  "badge": false,
  "faceAnchor": 0.30,
  "badgeUntil": 0
}
```
- خلفية: أخضر مائل للرمادي `#6d8b81`
- تمييز: أصفر `#ffde59`
- مساعدة: أبيض، أسود، بيج `#EDE6D6`
- نص فوق الخلفية: أبيض
- الخط: **Cairo** (اختاره كلود — هندسي وعصري يناسب برنامجاً تدريبياً؛ الهوك بوزن Black، النص SemiBold)
